Install Core as a project dependency:

<Tabs groupId="package-manager">
  <TabItem value="npm" label="npm">

    ```bash
    npm install @global-cache/core
    ```

  </TabItem>
  <TabItem value="yarn" label="Yarn">

    ```bash
    yarn add @global-cache/core
    ```

  </TabItem>
  <TabItem value="pnpm" label="pnpm">

    ```bash
    pnpm add @global-cache/core
    ```

  </TabItem>
</Tabs>

Core requires Node.js 20 or later.

You are ready to [configure Core](./configuration.md), then review how its
[client and server fit together](./architecture.md).
